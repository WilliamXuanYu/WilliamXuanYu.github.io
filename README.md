# Sining Ang - Academic Homepage

This repository hosts the GitHub Pages site for `WilliamXuanYu.github.io`.

The site is a lightweight static academic homepage with:

- English as the default language
- Chinese/English language toggle
- View-based navigation for overview, research, publications, patents, projects, and education
- Click-to-switch profile photos
- No build step required

Edit the content in `assets/js/main.js` and styles in `assets/css/styles.css`.
